# Simple Casino (Forge 1.21.1)

Слот-машина: ставки **1 / 5 / 10 / 20** алмазов.

## Как играть
1. Скрафти **Slot Machine**: железо + редстоун + алмаз (см. рецепт).
2. Поставь блок, ПКМ — откроется GUI.
3. **Bet** — переключить ставку (1→5→10→20→1).
4. **SPIN** — списать алмазы и крутить.

### Выигрыши (три одинаковых)
| Символ  | Множитель |
|---------|-----------|
| Cherry  | ×2        |
| Lemon   | ×3        |
| Diamond | ×5        |
| Seven   | ×10       |
| BAR     | ×20       |

## Сборка
JDK 21 + Forge MDK 1.21.1 (`gradlew` + `gradle/`):

```bash
./gradlew build
```

Jar: `build/libs/SimpleCasino-1.0.0.jar`

## Примечание
Сеть и GUI рассчитаны на Forge 1.21.1. Если `ChannelBuilder` / пакеты не скомпилируются — пришли лог, подправим API.
